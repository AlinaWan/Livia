## Prerequisites

* [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)

## Usage

Run any macro project directly using the .NET CLI:

```powershell
dotnet run --project Apps/<Experience>/<Macro>
```
